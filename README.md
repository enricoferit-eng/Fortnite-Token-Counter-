# Fortnite Token Counter

Kisten zählen im Team: Lobby erstellen, Link teilen, jeder tippt bei jeder geöffneten Kiste.
Der Team-Zähler läuft live bei allen, mit Rangliste und der Chance auf den Token (1 zu 137.500).

- `index.html` – die ganze Seite
- `supabase.js` – Supabase-Bibliothek (supabase-js 2.118.0), lokal mitgeliefert
- Daten liegen in Supabase (Tabellen `lobbies` und `players`)

Inoffizielles Fan-Tool, nicht von Epic Games.
